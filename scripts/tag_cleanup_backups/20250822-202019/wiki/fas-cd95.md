# FAS (CD95)

**What it is.** Death receptor on the cell surface; when engaged, triggers apoptosis.

**Why it matters here.** Provides an extrinsic kill route; some cancers down-regulate it.

**Notes.** Type: TNF receptor superfamily; Ligand: FasL.
