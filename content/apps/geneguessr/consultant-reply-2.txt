Use Quartz’s `externalResources` path (or a tiny front-matter flag + conditional) and compute URLs with `pathToRoot`. Below is a dead-simple fix (works today), plus the “clean” pattern Quartz expects.

# What the docs & code show (online)

* Quartz distinguishes path types and expects you to compute URLs with `pathToRoot(slug)` so assets resolve from any page depth. Don’t hard-code `/static/...`. ([quartz.jzhao.xyz][1])
* During emit, Quartz **gathers static resources** declared for a page and renders them via `Head` using helpers like `JSResourceToScriptElement`. That’s the intended way to inject JS/CSS; not ad-hoc logic in `Head.tsx`. ([quartz.jzhao.xyz][2])
* You can see this in forks: the emitter calls `pageResources(pathToRoot(slug), file.data, resources)` and `Head` turns those into `<link>`/`<script>` tags. ([Anson | Git][3])
* There’s even a Quartz issue about **injecting external scripts** using `externalResources`—the API exists and is meant for this. ([GitHub][4])
* Your live site footer confirms Quartz 4.5.1, so these mechanisms apply. ([Brinedew][5])

# Fix that’s least invasive (works with your current structure)

**Goal:** only load Geneguessr assets on `/apps/geneguessr`, with correct relative paths, and stop relying on an IIFE.

### 1) Rewrite the conditional in `quartz/components/Head.tsx`

Use a plain boolean + `pathToRoot`. (Quartz recommends this helper for URLs. ([quartz.jzhao.xyz][1]))

```tsx
// quartz/components/Head.tsx
import { pathToRoot } from "../util/path"

export default (() => {
  function Head({ fileData }: QuartzComponentProps) {
    const slug = Array.isArray(fileData.slug) ? fileData.slug.join("/") : ""
    const root = pathToRoot(fileData.slug)
    const isGeneguessr = slug === "apps/geneguessr" || fileData.frontmatter?.title === "Geneguessr"

    return (
      <>
        {/* ...existing head stuff... */}

        {isGeneguessr && (
          <>
            <link rel="stylesheet" href={`${root}static/geneguessr/styles.css?v=1`} />
            <script defer src={`${root}static/geneguessr/app.js?v=1`}></script>
          </>
        )}
      </>
    )
  }
  return Head
})()
```

Why this helps:

* No IIFE; Preact SSR just emits the nodes.
* Uses `pathToRoot` so the built HTML for `/apps/geneguessr.html` gets `../static/...` (correct). ([quartz.jzhao.xyz][1])

### 2) Make the JSON fetch resilient (your app code)

Avoid a hard-coded `/static/...` so preview subpaths and CDN rewrites don’t break.

```js
// content/static/geneguessr/app.js
function resolveStaticBase() {
  const root = document.getElementById('geneguessr-root')
  if (root?.dataset?.static) {
    let u = root.dataset.static
    return u.endsWith('/') ? u : `${u}/`
  }
  const s = document.currentScript?.src
  if (s) return s.replace(/app\.js(\?.*)?$/, '')
  return '/static/geneguessr/' // last-resort fallback
}

const STATIC_BASE = resolveStaticBase()

async function loadProteins() {
  const resp = await fetch(`${STATIC_BASE}proteins.json`, { cache: 'no-store' })
  if (!resp.ok) throw new Error(`Failed to load proteins: ${resp.status}`)
  return resp.json()
}
```

### 3) Keep the root hint in your page

```md
<!-- content/apps/geneguessr.md -->
<div id="geneguessr-root" data-static="../static/geneguessr"></div>
```

### 4) Clean rebuild

Delete `public/` and any Quartz caches, rebuild, hard-refresh.

**Why this probably fixes your “scripts missing”**
Quartz’s `Head` is part of a pipeline that collects & emits resources. In practice, inline execution blocks inside JSX can get optimized away or not run as you think during SSR; using a simple boolean branch avoids that class of failure, and the `pathToRoot`-computed URLs match Quartz’s path semantics. ([quartz.jzhao.xyz][2])

# “Clean” Quartz way (front-matter driven, future-proof)

If you want to stop touching `Head.tsx` for every app, use a **front-matter contract** plus a tiny helper in `Head.tsx` to read `externalResources` the way Quartz expects. (This mirrors what the emitter/Head helpers are designed for. ([Guardian Project][6]))

**Page front-matter (geneguessr.md):**

```yaml
---
title: "Geneguessr"
assets:
  css:
    - static/geneguessr/styles.css?v=1
  js:
    - src: static/geneguessr/app.js?v=1
      loadTime: afterDOMReady
---
<div id="geneguessr-root" data-static="../static/geneguessr"></div>
```

**Head.tsx (generic loader):**

```tsx
// inside Head()
const root = pathToRoot(fileData.slug)
const assets = (fileData.frontmatter as any)?.assets
const css: string[] = assets?.css ?? []
const js: { src: string, loadTime?: "beforeDOMReady" | "afterDOMReady" }[] = assets?.js ?? []

{css.map((p, i) => <link key={`p-css-${i}`} rel="stylesheet" href={`${root}${p}`} />)}
{js.map((spec, i) => (
  <script
    key={`p-js-${i}`}
    defer={spec.loadTime !== "beforeDOMReady"}
    src={`${root}${spec.src}`}
  />
))}
```

That’s aligned with the **resources > Head emission** Quartz talks about in the architecture/docs and seen in forks/issues. ([quartz.jzhao.xyz][2])


View-source should show it on `/apps/geneguessr`. If not, your `Head.tsx` build isn’t actually getting picked up—nuke caches and ensure you’re editing the right copy of Quartz.

2. **Verify computed URLs**
   In `/apps/geneguessr.html`, links should look like:

```html
<link rel="stylesheet" href="../static/geneguessr/styles.css?v=1">
<script defer src="../static/geneguessr/app.js?v=1"></script>
```

If they start with `/static/…`, you’re not using `pathToRoot`. (Quartz’s path docs explain why root-relative breaks subpath/preview builds. ([quartz.jzhao.xyz][1]))

# Why Scriptotic “just works” but Geneguessr didn’t

Scriptotic’s assets were globally injected and didn’t rely on a JSON fetch path, so it dodged both the **SSR conditional** and **relative-URL** footguns. Geneguessr had both (conditional add + `/static/...` fetch), so it looked blank even though your app code is fine.

## Recommended pattern (so you don’t re-debug this)

* Put each app under `content/static/apps/<name>/…` (or your current `static/geneguessr/…`)
* Make a page folder: `content/apps/<name>/index.md`
* Use `pathToRoot(slug)` for all URLs Quartz emits. ([quartz.jzhao.xyz][1])
* Either:

  * (A) **Front-matter `assets`** → generic Head reads and emits; or
  * (B) **Per-page boolean in Head** using the slug; keep it boring and explicit.
* In JS, derive your **data base URL at runtime** (`currentScript` or `data-static`).
* Guard the boot: if `#<name>-root` isn’t present, do nothing.
