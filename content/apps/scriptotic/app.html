🔧 For Developers: Running Your Own Instance

Want to run Scriptotic yourself? The transcription backend runs on:

  • Hardware: RTX 4080 (12GB VRAM) or similar GPU
  • Model: Voxtral Mini 3B via vLLM
  • Setup: Windows + WSL2 + Python Flask API
