# Giving each human gene a human (ish) face

A protocol/methods section

1. Make a database row for each gene of interest
2. Collect info from genetic and protein databases
	1. database 1
	2. database 2
	3. database 3...
3. First batch of mapping are anchors: simple algorithmic mappings
	1. Transmembrane/soluble to male/female
	2. Year of discovery to apparent age
	3. Molecular weight to apparent weight...
4. Let the model write a manifestation based on each gene essence
	1. manifestations are multi-paragraph character designs
	2. optionally, translate each manifestation into a list of tags that would be suitable to danbooru
5. Collect a set of emulsions. Emulsion is an image style prompt tied to a specific model workflow. Iconoplasm starts with thousands of emulsions, a
6. Put the emulsion on a manifestation to obtain an actual image file. 
	1. Same manifestation may have multiple images through different emulsions
	2. You may discover that some emulsions are better at certain types of characters (e.g. chibi art style for sub-10kg characters)
